Scope disclosure

The swap step in every run below executes against mock_swap, a program I built and deployed myself as an explicit stand-in for a real swap venue (fixed-rate, real token transfers, real failure on insufficient pool liquidity — not a simulation). It is not Orca, Jupiter, Raydium, or any production DEX. Full detail: KNOWN_LIMITATIONS.md.

Try it yourself

Requires: Node 20+, a funded Solana devnet keypair (solana airdrop works), Anchor CLI if you want to rebuild from source.

git clone https://github.com/Portaudit/trustrail-pipelines
cd trustrail-pipelines/worker
npm install
npm run create-commitment
npm run withdraw-for-swap
npm run execute-mock-swap
npm run submit-proof
npm run get-commitment -- <commitment-address>

These are the exact scripts in worker/package.json — nothing here is simplified from what's actually in the repo.
